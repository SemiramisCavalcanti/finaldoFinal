# ☕ Café Morada

O **Café Morada** é uma aplicação web desenvolvida para simular a gestão do cardápio de um café e informações básicas através de uma experiência interativa inspirada em jogos RPG. O projeto combina desenvolvimento web, interface intuitiva e elementos de gamificação para criar uma forma diferente de navegar e gerir um estabelecimento.
O utilizador pode explorar o ambiente, interagir com personagens (NPCs), aceder a diferentes áreas do café e executar funcionalidades administrativas de forma visual e dinâmica. O sistema foi pensado para ser modular, permitindo futuras expansões, como áreas de aprendizagem, conteúdos exclusivos, inteligência artificial e personalização para diferentes clientes.

### Funcionalidades
* Ambiente interativo em estilo RPG.
* Navegação por mapa com movimentação do personagem.
* Interação com NPCs e objetos do cenário.
* Sistema de gestão do café.
* Interface responsiva e intuitiva.
* Estrutura preparada para expansão de funcionalidades.

### Tecnologias
* HTML5
* CSS3
* JavaScript
* Canvas API
* Git & GitHub

### Objetivo

O projeto demonstra a integração entre desenvolvimento web e experiências interativas, explorando conceitos de UX/UI, programação e gamificação para criar uma aplicação moderna, envolvente e escalável.
